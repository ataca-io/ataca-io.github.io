# Project: ataca.io

## Overview
GitHub Pages landing page for ataca.io - a cloud services provider.

## Tech Stack
- Pure HTML/CSS/JS (single page)
- Tailwind CSS via CDN
- Google Fonts (Inter)
- Minimal custom CSS

## Content
- Simple hero section with CTA
- Navigation: Services, Solutions, About, Contact
- Footer with Services, Company, Legal links

## Files
- `index.html` - Main landing page (199 lines)
- `theme.js` - Tailwind config with the Ataca Console design tokens
- `README.md` - Basic repo description
- `CNAME` - Domain: ataca.io

## Design
- Dark slate background (#0f172a)
- Follows the Ataca Console design system; tokens live in `theme.js`
- Indigo accent #818cf8 for buttons, #a5b4fc for links; #4f46e5 only for the logo mark
- Clean, minimal aesthetic
- Mobile responsive
